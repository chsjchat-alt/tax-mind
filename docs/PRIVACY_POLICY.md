## 一、信息收集

1. **企业数据**：企业名称、统一社会信用代码、行业类型、财务指标、纳税申报数据
2. **个人信息**：用户名、姓名、电子邮箱（AES-256-GCM 加密存储）
3. **操作日志**：登录时间、IP 地址、操作行为（用于审计追溯）
4. **第三方数据**：银行流水、发票数据、合同台账等业务财务数据

## 二、信息使用

- 财税合规风险评估与决策支持
- 税务优化建议与方案模拟
- 合规报告生成
- 系统安全审计与运行监控

## 三、数据保护

| 措施 | 说明 |
|------|------|
| 传输加密 | TLS 1.3 + HSTS |
| 存储加密 | AES-256-GCM 字段级加密 |
| 访问控制 | RBAC 三级角色 + JWT 认证 |
| 审计日志 | 全量 API 请求记录 |
| 数据库 | PostgreSQL SSL 连接 + scram-sha-256 |
| 备份 | 每日自动备份，保留 30 天 |

## 四、数据保留

- 企业数据：服务期间 + 合同终止后 90 天
- 审计日志：至少保留 6 个月（等保 2.0 要求）
- 备份数据：滚动保留 30 天

## 五、用户权利

- 数据导出权：可请求导出本企业全部数据
- 数据删除权：合同终止后可请求删除数据
- 知情权：告知数据处理目的、范围、周期
