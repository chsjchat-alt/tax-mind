#  数据处理协议 (Data Processing Agreement)
#  「税智·心判」财税合规决策支持系统
#
#  本协议为服务合同附件，适用于服务提供方（数据处理者）
#  处理客户（数据控制者）委托的财税数据。
#
#  法律依据：
#    - 《中华人民共和国个人信息保护法》
#    - 《中华人民共和国数据安全法》
#    - GB/T 35273-2020《个人信息安全规范》
# ══════════════════════════════════════════════════════════════════

## 一、定义

| 术语 | 定义 |
|------|------|
| 数据控制者 | 委托处理数据的客户方 |
| 数据处理者 | 提供财税合规分析服务的平台方 |
| 个人数据 | 可识别自然人身份的信息（姓名、邮箱等） |
| 企业数据 | 企业的财税、经营、合同等商业数据 |

## 二、处理范围与目的

**处理目的**：财税合规风险评估、方案模拟、合规报告生成

**数据类别**：
- 企业基础信息（名称、信用代码、行业）
- 财税数据（申报表、发票、银行流水、财务报表）
- 用户账户信息（用户名、姓名、邮箱）

**处理期限**：服务合同有效期 + 终止后 90 天

## 三、数据处理者义务

### 3.1 安全措施

| 措施 | 实施情况 |
|------|----------|
| 访问控制 | RBAC（admin/auditor/viewer）+ 多租户隔离 |
| 传输加密 | TLS 1.3 |
| 存储加密 | AES-256-GCM 字段级加密 |
| 认证 | JWT + OAuth2 + bcrypt |
| 审计 | 全量 API 审计日志 |
| 备份 | 每日自动备份，30天保留 |

### 3.2 保密义务

- 数据处理者人员签署保密协议
- 仅授权人员在业务需要范围内访问数据
- 禁止将数据用于约定目的之外的用途

### 3.3 数据泄露通知

发生数据泄露事件时，数据处理者应在 **24 小时内**：
1. 通知数据控制者
2. 说明泄露数据类别、数量、可能影响
3. 提供已采取和拟采取的补救措施
4. 配合数据控制者向监管机构报告

### 3.4 子处理者

使用子处理者需事先获得数据控制者书面同意，并通过合同约束子处理者遵守同等数据保护义务。

## 四、数据主体权利响应

数据处理者应协助数据控制者响应数据主体的：
- 访问权
- 更正权
- 删除权
- 数据可携权
- 限制处理权

响应时限：收到请求后 **15 个工作日**内

## 五、数据处理记录

数据处理者应保存以下记录：
- 处理活动日志（审计日志，保留 6 个月）
- 访问控制变更记录
- 安全事件报告
- 数据备份/恢复记录

## 六、协议终止

服务终止后：
1. 数据处理者应在 90 天内删除所有委托数据
2. 提供数据导出服务（如客户要求）
3. 出具数据删除证明
