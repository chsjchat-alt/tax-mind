### 3.2 核心模块职责划分

| 模块 | 职责 | 依赖方向 | 评价 |
|------|------|----------|:----:|
| `core/` | 7 个纯函数财税引擎（四流匹配、风险评分、罚款计算、模拟推演、优惠校验、干预策略、通用风险评分） | 零依赖（仅依赖 Python stdlib + Decimal） | ★★★★★ |
| `api/` | 路由层，参数校验 → 委托 service → 返回 Pydantic 响应 | → services, schemas | ★★★★ |
| `services/` | 业务编排层（数据加载、富化、持久化、LLM 调用） | → core, models | ★★★★ |
| `models/` | SQLAlchemy ORM 模型定义 | 零业务逻辑依赖 | ★★★★★ |
| `schemas/` | Pydantic V2 请求/响应校验 | 零依赖 | ★★★★★ |
| `utils/` | 统一响应格式 + 异常码体系 | 零依赖 | ★★★★ |

**关键架构优势:**
- `core/` 引擎层为纯函数，可独立单元测试，无数据库/网络依赖
- 消除了跨模块循环依赖（依赖方向严格单向: api → services → core）
- Schema 层与 ORM 层分离，避免 Pydantic/SQLAlchemy 耦合

**架构合理性评分: 88/100 (A-)**
